RUKHSAAR CLOTHES - website + admin panel

START (Windows): install Node.js (nodejs.org), then double-click start.bat
START (Mac/Linux): ./start.sh

Website: http://localhost:3000
Admin:   http://localhost:3000/admin   (first password: admin123 - change it in the Account tab)

First thing: Admin > Banner & Site > put your WhatsApp number (923001234567 format).
Photos in the demo are placeholders - replace them in Admin > Products before going live.
To put the site online you need a Node.js host (Railway, Render, VPS). Keep the "data" and "public/uploads" folders persistent.
